# Convertidor de Archivos a PowerPoint

Una aplicación web sencilla para convertir archivos comunes (imágenes, texto) a archivos PPTX de Microsoft PowerPoint.

## Funcionalidades

- Sube múltiples archivos (imágenes JPG/PNG, archivos de texto TXT).
- Convierte cada archivo a una diapositiva en un PPTX.
- Descarga el archivo PPTX generado.

## Cómo usar

1. Abre index.html en un navegador.
2. Selecciona los archivos a convertir.
3. Haz clic en "Convertir a PPTX".
4. Descarga el archivo generado.
